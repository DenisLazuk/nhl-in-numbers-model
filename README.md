# НХЛ в цифрах — модель

Модель оценивает, кто скорее выиграет матч НХЛ, только по данным, которые были известны до игрового дня. Сравниваются хозяева и гости: ожидаемые голы в равных составах, голы без пустых ворот, спецбригады, сейвы, форма за 10 матчей, свой лёд, два матча подряд и гонка за плей-офф.

Это код метода. Его можно прочитать. Это не разрешение копировать продукт и не приглашение ставить.

- Сайт: https://hockeynumbers.app/model.html
- Канал: https://t.me/hockey_v_cifrah
- Публичный журнал: https://docs.google.com/spreadsheets/d/1M31sb4BrVShDnP8vDQ5Uu8XVO5QlsAJz_UFvcX7i_oc/edit

Не аффилированы с НХЛ. Это не капперский продукт и не совет, куда ставить. 18+.

## Цифры

На 6 559 матчах сезонов 2021–2026 средняя точность прогноза победителя — 59,4%.

Сезон 2025–26, 1 312 игр, каждый матч посчитан только на данных до этой даты:

| Показатель | Значение |
|---|---|
| Точность прогноза победителя | 53,8% |
| Если всегда выбирать хозяев | 52,2% |
| Ошибка вероятностей, меньше лучше | 0,245 |
| Точность, когда модель уверена / средне / сомневается | 63,0% / 56,5% / 46,9% |

Веса стоят константами в начале `scripts/nhl_predict.py`. Сезонные рейтинги сжимаются к прошлому сезону: `w = GP / (GP + 20)`. Итог умножается на температуру `0.30`.

## Откуда данные

- Официальный NHL API: расписание, счета, таблица, голы, большинство, меньшинство, броски.
- [MoneyPuck.com](https://moneypuck.com/): ожидаемые голы по матчам. Кредит: MoneyPuck.com. Файлы с [data.htm](https://moneypuck.com/data.htm) бесплатны для некоммерческого разбора. Коммерческое использование этих файлов — только после письма на moneypuck.com@gmail.com.

В этом расчёте нет Evolving-Hockey и нет SportsDataIO.

## Как запустить

Нужен Python 3.12.

```bash
pip install -r requirements.txt
python scripts/nhl_predict.py --date 2026-03-31
```

Полный бэктест качает данные НХЛ и MoneyPuck и здесь в проверках не гоняется:

```bash
python scripts/backtest.py
```

Снимок «на дату», стартовый вратарь и ручной штраф за травму лежат в SQLite. Без базы модель ходит в API напрямую, а вратаря и травму не подставляет.

```bash
python scripts/nhl_etl_cli.py init
python scripts/nhl_etl_cli.py sync --date 2026-03-31
```

Ручные файлы, если они нужны: `data/manual/projected_goalies.csv` и `data/manual/injuries.csv`. Образец колонок — рядом, в файлах `*.example.csv`. Пока своего файла нет, читается образец.

Кэш MoneyPuck и база в git не входят. Их скрипт собирает сам.

# НХЛ в цифрах — модель

Модель оценивает вероятность, кто скорее всего выиграет матч НХЛ, только по данным, которые были известны до игрового дня. Сравниваются хозяева и гости: ожидаемые голы в равных составах, голы без пустых ворот, спецбригады, сейвы, форма за 10 матчей, свой лёд, бэк-ту-бэк и гонка за плей-офф.

Это код модели, его можно прочитать, это не разрешение копировать продукт и не приглашение делать ставки.

- Сайт: https://hockeynumbers.app/model.html
- Канал: https://t.me/hockey_v_cifrah
- Публичный трекинг прогноз/факт: https://docs.google.com/spreadsheets/d/1M31sb4BrVShDnP8vDQ5Uu8XVO5QlsAJz_UFvcX7i_oc/edit

Не аффилированы с НХЛ, это не капперский продукт.

## Цифры

На 6 559 матчах сезонов 2021–2026 средняя точность прогноза победителя — 59,4%.

Сезон 2025–26, 1 312 игр, каждый матч посчитан только на данных до этой даты:

| Показатель | Значение |
|---|---|
| Точность прогноза победителя | 53,8% |
| Если всегда выбирать хозяев | 52,2% |
| Ошибка вероятностей, меньше лучше | 0,245 |
| Точность, когда модель уверена / средне / сомневается | 63,0% / 56,5% / 46,9% |

Веса стоят константами в начале `scripts/nhl_predict.py`. Сезонные рейтинги сжимаются к прошлому сезону: `w = GP / (GP + 20)`. Итог умножается на коэффициент `0.30`.

**Коэффициент** (константа `DELTA_SCALE` в коде) — это множитель на сумму всех вкладов, перед тем как она становится вероятностью победы.

Сначала модель складывает разницу хозяев и гостей: ожидаемые голы, сейвы, свой лёд и остальные признаки. Потом умножает эту сумму на 0.30. Потом переводит число в вероятность: `1 / (1 + e^(−сумма × 0.30))`.

0.30 уменьшает разрыв, если сырая сумма равна 1.0, без множителя вероятность была бы около 73%. После умножения на 0.30 получается около 57%, сильный перевес по признакам не превращается в 80–90%.

Коэффициент подобрал на октябре–декабре 2025 и проверил на январе–апреле 2026. **Ошибка вероятностей** после этого шага стала 0.243 вместо 0.250.


## Откуда данные

- Официальный NHL API: расписание, счета, таблица, голы, большинство, меньшинство, броски.
- [MoneyPuck.com](https://moneypuck.com/): ожидаемые голы по матчам.

## Как запустить

Нужен Python 3.12.

```bash
pip install -r requirements.txt
python scripts/nhl_predict.py --date 2026-03-31
```

Полный бэктест качает данные НХЛ и MoneyPuck и здесь в проверках не запускается:

```bash
python scripts/backtest.py
```

Снимок «на дату», стартовый вратарь и ручной штраф за травму должны лежать в SQLite. В текущей версии продукта базы нет. Без базы модель ходит в API напрямую, а вратаря и травму не подставляет.

```bash
python scripts/nhl_etl_cli.py init
python scripts/nhl_etl_cli.py sync --date 2026-03-31
```

Ручные файлы, если они нужны: `data/manual/projected_goalies.csv` и `data/manual/injuries.csv`. Образец колонок — рядом, в файлах `*.example.csv`. Пока своего файла нет, читается образец.

Кэш MoneyPuck и база в репозиторий не входят, их скрипт собирает сам.
